# Episódio 01: Do texto aos números

**Pergunta:** como uma pergunta se torna uma entrada que a rede neural consegue processar?

**Ao final**, a pessoa deve distinguir um token, seu ID e seu vetor inicial, acompanhar o caminho até a entrada do Transformer e explicar por que contar palavras não mede tokens com precisão.

Três slides extras ficam fora dos 50 minutos: distinção de embeddings para busca, resumo comparativo e fontes. O índice permite acessá-los durante as perguntas. A navegação normal termina no slide de perguntas.

O exemplo usa “Explique crédito rural.”. Todos os recortes, IDs e valores da matriz são fictícios, para ilustrar o processamento. As notas explicam os limites de cada analogia. O episódio termina na entrada do Transformer.
